## Changes

- Keep the complete approved American-English research, writing, QA and targeted-repair pipeline intact.
- Add one Codex `translate` stage **after** final English editorial PASS (not a separate research/draft).
- Emit `output/<slug>_slope3_en_US.html` and `output/<slug>_slope3_vi_VN.html`; both reference one `output/assets/` directory.
- Translate six headings to their fixed Vietnamese equivalents, including the Vietnamese References / Image Credits labels.
- Add hard structural translation QA: preserve article title, paragraph count and order, source token sequence per paragraph, and image IDs and order.
- Use SHA-256 of approved `article.json` to invalidate obsolete translations on resume/export. Retry failed translation at most twice.
- Use `codex exec --json` to track the `turn.completed` token usage for each model invocation, including retries and translation. Store `token_usage.json` and human-readable `token_usage.md` for each run.
- Include per-stage input, cached input (subset of input), output, and totals; never fabricate tokens when CLI usage is missing.
- Keep each Codex run log separate, so repeated Critic and Repair calls cannot overwrite earlier event streams.
- Add `python run.py usage --run-dir <path>` to inspect usage later.
- Existing EN DOCX and EN Markdown are retained, unchanged in layout and purpose.

## Constraints / honest caveats

- Codex must be installed, authenticated with ChatGPT and support the CLI JSON-event option for precise token reporting.
- ChatGPT subscription quota is not directly represented by usage token counts. No price or remaining quota is calculated.
- Python translation QA checks structural alignment, not the full semantic fidelity of every Vietnamese sentence. Editorial review is still recommended before publishing.
- A live Codex end-to-end execution was not possible in the build container; Python unit and export integration tests were executed.

## Windows upgrade

1. Extract into a **new folder**; keep old `runs/` and settings as backup.
2. If customizing `config.json`, copy your own settings to the new file while retaining `max_translation_attempts`.
3. Reuse an already-approved article folder with `python run.py export --run-dir "D:\\GameSEO\\runs\\my-game"` (the EN critique and QA must still pass).
4. The same run can be reopened with `python run.py usage --run-dir "D:\\GameSEO\\runs\\my-game"`.
